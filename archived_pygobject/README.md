# Archived GTK 4 / PyGObject Implementation

This folder contains the original GTK 4 (PyGObject + libadwaita) implementation of the External Drive Media Organizer application.

## Running the Archived PyGObject UI
To run this version:
```bash
python3 main.py
```
*Note: Requires system GTK 4, Libadwaita, and `pygobject` installed.*
